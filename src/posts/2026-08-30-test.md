I recently started to use Room EQ Wizard (REW). Before this, my digital signal processing (DSP) work was only in the computer. I wrote C++ code and tested audio buffers. REW is different. It measures the physical space.



Digital Code vs. Physical Rooms



In software, a digital filter does exactly what the math says. If you write the correct code, the result is perfect.



In the real world, the room changes the audio. Sound waves bounce off walls. The reflections cause phase cancellations and frequency peaks. A flat speaker does not sound flat in a bad room.



To fix this problem, you must measure the room.

The Impulse Response



When the sweep finishes, REW calculates the impulse response. The impulse response is a mathematical model of the room. It shows the exact acoustic properties of your space.



This measurement is the foundation of my room correction project. I exported the impulse response from REW. Then, I used a Python pipeline to calculate a Kirkeby-regularized inverse filter. Finally, I loaded that filter into a JUCE plugin to correct the sound in real time.
